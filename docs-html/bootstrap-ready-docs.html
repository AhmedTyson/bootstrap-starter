نظام الألوان (Color System)

يعني ايه CSS Variables؟ ببساطة دي زي "علب" بتحط فيها القيم اللي بتستخدمها كتير (زي الألوان). بدل ما تكتب الكود اللوني #0d6efd في 50 مكان مختلف، بتحطه مرة واحدة في متغير وبتستخدم الاسم بتاعه في كل حتة. لو عايز تغير اللون، بتغيره في مكان واحد بس وهيتغير في كل الموقع!
What are CSS Variables? Simply put, they're like "containers" where you store values you use frequently (like colors). Instead of writing the color code #0d6efd in 50 different places, you define it once in a variable and use its name everywhere. If you want to change the color, you change it in one place and it updates across the entire site!

    /* الألوان الأساسية - Primary Colors */
    --primary-color: #0d6efd;    /* الأزرق الرئيسي */
    --success-color: #198754;    /* أخضر للنجاح */
    --danger-color: #dc3545;     /* أحمر للأخطاء */
    --warning-color: #ffc107;    /* أصفر للتحذيرات */
    
    /* المسافات - Spacing */
    --spacer-sm: 0.5rem;   /* 8px - مسافة صغيرة */
    --spacer-md: 1rem;     /* 16px - مسافة متوسطة */
    --spacer-lg: 1.5rem;   /* 24px - مسافة كبيرة */
    --spacer-xl: 3rem;     /* 48px - مسافة أكبر */
    
    /* الخطوط - Typography */
    --font-main: 'Inter', sans-serif;
    --font-arabic: 'Noto Naskh Arabic', serif;
}

نموذج الصندوق (Box Model)

كل عنصر في الصفحة (سواء كان Div أو Button أو أي حاجة) هو عبارة عن "صندوق" محاط بـ 4 طبقات. تخيل إنك بتلف هدية: المحتوى (Content) هو الهدية نفسها، الـ Padding هو الفلين اللي بيحميها، الـ Border هو الكرتونة، والـ Margin هي المسافة بينها وبين الهدايا التانية.
Every element on the page (whether a Div, Button, or anything else) is a "box" surrounded by 4 layers. Imagine wrapping a gift: Content is the gift itself, Padding is the bubble wrap protecting it, Border is the box, and Margin is the space between it and other gifts.

نظام التخطيط Flexbox و Grid

Flexbox - التوزيع في بُعد واحد

الـ Flexbox ده زي لما بتحط حاجات في درج واحد وتوزعها. بتقدر تقول للعناصر "اتوزعوا على الجنبين" أو "اتجمعوا في النص" أو "خليهم متساويين". بيشتغل في اتجاه واحد بس (يا صف يا عمود).
Flexbox is like arranging items in a single drawer. You can tell elements to "spread to the sides" or "gather in the center" or "be equal". It works in one direction only (either row or column).

.flex-center {
    display: flex;
    justify-content: center;   /* توسيط أفقي ↔️ */
    align-items: center;      /* توسيط عمودي ↕️ */

.flex-between {
    display: flex;
    justify-content: space-between;
}

CSS Grid - التخطيط ثنائي الأبعاد

الـ Grid ده زي لما بترسم جدول على ورقة وتوزع الحاجات في الخانات. ممكن عنصر ياخد خانتين أو أكتر، وممكن تتحكم في عدد الأعمدة والصفوف زي ما إنت عايز. ده بيشتغل في اتجاهين (صفوف وأعمدة مع بعض).
Grid is like drawing a table on paper and distributing items in cells. An element can span multiple cells, and you can control the number of columns and rows as you wish. This works in two dimensions (rows and columns together).

المكونات الجاهزة

الأزرار (Buttons)

الأزرار هي أهم عنصر تفاعلي في أي موقع. لازم يكون شكلها واضح إن دي "حاجة تتضغط" ولازم يكون فيها تأثير Hover عشان المستخدم يحس إنها بتستجيب.
Buttons are the most important interactive element on any website. They should look obviously "clickable" and must have a hover effect so users feel they're responsive.
أنماط الأزرار المختلفة | Button Varieties
.btn-primary {
    background: var(--primary-color);
    color: white;
    padding: 12px 24px;
    border-radius: 8px;
    border: none;
    cursor: pointer;
    transition: all 0.3s ease;
}

.btn-primary:hover {
    transform: translateY(-2px);      /* بيطلع لفوق شوية */
    box-shadow: 0 4px 15px rgba(13, 110, 253, 0.4);
}

البطاقات (Cards)

الـ Cards دي بتتستخدم في كل حتة: منتجات، مقالات، مميزات الموقع. الفكرة إنها "حاوية" بتجمع معلومات مع بعض عشان تبان وحدة واحدة. لازم يكون فيها Hover Effect عشان تحسس إنها Interactive.
Cards are used everywhere: products, articles, features. The idea is that they're "containers" grouping related information as a single unit. They must have a hover effect to feel interactive.

الطباعة ودعم العربية

التسلسل الهرمي للنصوص

مهم جداً إن الـ Headings تكون بأحجام مختلفة عشان عين القارئ تعرف إيه الأهم. H1 هو العنوان الرئيسي (أكبر حاجة)، وكل ما ننزل رقم يصغر الحجم. النص العادي (paragraph) أصغر من كلهم.
It's crucial that Headings have different sizes so readers can identify what's important. H1 is the main heading (largest), and as numbers increase, sizes decrease. Regular text (paragraph) is smallest of all.
أحجام العناوين والنصوص | Typography Scale
H1 - العنوان الرئيسي (Main Heading)
H2 - العنوان الفرعي (Subheading)
H3 - عنوان القسم (Section Title)
Body Text - النص العادي للفقرات والمحتوى
Small Text - نص صغير للملاحظات

دعم RTL والعربية

لما بتشتغل على موقع عربي، لازم تعكس الاتجاه من اليسار لليمين (LTR) لليمين لليسار (RTL). ده بيتعمل على مستوى الـ HTML نفسه وبعدين بالـ CSS لو محتاج تستثني عناصر معينة زي الأكواد.
When working on an Arabic site, you need to flip direction from Left-to-Right (LTR) to Right-to-Left (RTL). This is done at the HTML level, then with CSS if you need to exclude certain elements like code. 
<!-- في ملف HTML - إعداد الصفحة للعربية -->
<html lang="ar" dir="rtl">

/* في CSS - كلاسات مفيدة */
.rtl {
    direction: rtl;
    text-align: right;
}

.ltr {
    direction: ltr;
    text-align: left;
}

/* الأكواد دايماً LTR حتى في موقع عربي */
code, pre {
    direction: ltr;
    text-align: left;
}

التصميم المتجاوب

نقاط التوقف (Breakpoints)

الـ Breakpoints دي زي "حدود" بتقول للمتصفح "لما الشاشة توصل لعرض معين، غير الشكل". يعني لو الشاشة صغيرة، خلي الأعمدة تنزل تحت بعض بدل ما تكون جمب بعض.
Breakpoints are like "boundaries" telling the browser "when the screen reaches a certain width, change the layout". So if the screen is small, stack columns vertically instead of horizontally.
النوع العرض الاستخدام (Usage)
📱 Mobile < 576px هواتف صغيرة - Small phones
📱 Mobile+ 576px - 767px هواتف عادية - Standard phones
📲 Tablet 768px - 991px أجهزة لوحية - Tablets
💻 Desktop 992px - 1199px شاشات متوسطة - Medium screens
🖥️ Desktop+ ≥ 1200px شاشات كبيرة - Large screens 
/* للموبايل (الشاشات الصغيرة) */
@media (max-width: 768px) {
    .container {
        padding: 20px;  /* مسافات أقل */
    }
    
    .hide-mobile {
        display: none;  /* إخفاء عناصر معينة */
    }
    
    .grid-container {
        grid-template-columns: 1fr;  /* عمود واحد */
    }
}

/* للديسكتوب */
@media (min-width: 769px) {
    .hide-desktop {
        display: none;
    }
}
