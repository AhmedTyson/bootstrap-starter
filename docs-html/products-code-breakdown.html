نظرة عامة (Overview)

الملف ده بيشرح بالتفصيل الكود اللي في products.html الخاص بمشروع Cera Project. هنركز بالذات على إزاي بنستخدم Bootstrap 5.3 عشان نبني الـ Layout (التصميم)، والـ Styling (الشكل)، والـ Interactivity (الحركات والتفاعلات) من غير ما نكتب كود CSS أو JS كتير.
This file explains the code in products.html of Cera Project. We focus on how Bootstrap 5.3 is used to build the Layout, Styling, and Interactivity without writing much custom CSS or JS.

الـ Head Styles & Dependencies

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
bootstrap.min.css: ده ملف الـ CSS الأساسي بتاع فريموورك Bootstrap. الملف ده بيوفرلنا حاجات مهمة زي:
  • Reset/Reboot: بيوحد شكل العناصر الأساسية في كل المتصفحات (زي تظبيط الـ margins والـ box-sizing).
  • Grid System: نظام تقسيم الصفحة (Containers, rows, columns) عشان الموقع يشتغل كويس على الموبايل واللابتوب (Responsive).
  • Components: تصميمات جاهزة بنستخدمها علطول زي الكروت (Cards)، المودالز / النوافذ المنبثقة (Modals)، والناف بار (Navbar).
  • Utilities: كلاسات سريعة عشان نتحكم في المسافات (Spacing)، المحاذاة (Alignment)، والألوان.
bootstrap.min.css: The core CSS file for Bootstrap framework. It provides essential features like:
  • Reset/Reboot: Unifies element styles across browsers (like fixing margins and box-sizing).
  • Grid System: Page layout system (Containers, rows, columns) for responsive design on mobile and laptop.
  • Components: Ready-to-use designs like Cards, Modals, and Navbar.
  • Utilities: Quick classes for controlling Spacing, Alignment, and Colors.

الناف بار هنا بيستخدم كلاسات Bootstrap القياسية عشان يعمل هيدر متجاوب (Responsive Header).

  • navbar: الكلاس الأساسي لتعريف الناف بار.
  • navbar-expand-lg: الكلاس دا بيقول للناف بار "افرد نفسك" وورينى كل اللينكات على الشاشات الكبيرة (Large screens ≥ 992px). لكن لو الشاشة أصغر من كده، لم اللينكات دي وحطها في زرار القائمة (Hamburger menu).
  • sticky-top: بتعمل position: sticky في الـ CSS. دي بتخلي الناف بار "يلزق" فوق في وش الشاشة وأنت بتعمل Scroll لتحت.
  • container: بيحجم عرض المحتوى في النص وبيسيب مسافات من الجناب (Margins) عشان الكلام مايبقاش لازق في حافة الشاشة.
  • navbar-brand: ده ستايل جاهز للوجو أو اسم الموقع (غالباً بيبقى الفونت أكبر والـ padding مظبوط).
  • navbar-toggler: ده الزرار اللي بيظهر على الموبايل عشان يفتح القائمة.
  • collapse navbar-collapse: ده الجراب (Wrapper) اللي شايل اللينكات، وهو اللي بيختفي ويظهر على الموبايل.
  • navbar-nav: كونتينر واخد Flexbox عشان يرص اللينكات جنب بعض.

The navbar uses standard Bootstrap classes to create a responsive header.

  • navbar: The base class defining the navbar.
  • navbar-expand-lg: Tells the navbar to "expand" and show all links on Large screens (≥ 992px). On smaller screens, it collapses links into a hamburger menu.
  • sticky-top: Applies position: sticky CSS. Keeps the navbar "stuck" to the top as you scroll down.
  • container: Constrains content width and adds side margins so text doesn't touch the screen edges.
  • navbar-brand: Pre-styled class for logos/site names (usually larger font and proper padding).
  • navbar-toggler: The mobile menu button that toggles the list.
  • collapse navbar-collapse: The wrapper containing the links, which hides/shows on mobile.
  • navbar-nav: Flexbox container for arranging links side-by-side.

  • row: ده "صف" بيشيل العواميد (Columns). الـ row بيعمل Negative Margin عشان يعادل الـ Padding بتاع العواميد.
  • col-12: يعني العمود ده هياخد عرض الصفحة بالكامل (12 من 12).
  • row g-4: صف بس فيه "Gutter" (فراغات بين العواميد) بمقدار 4 (1.5rem)، بالطول وبالعرض.
  • col-sm-6 col-lg-3: تحكم كامل في حجم العمود على حسب الشاشة:
    • Mobile (<576px): عشان مش محددين حاجة للموبايل، الديفولت إنه بياخد 100% من العرض (فوق بعض).
    • Small (≥576px): هياخد 6 من 12 (يعني 50% من العرض)، فكل منتجين هييجوا جنب بعض.
    • Large (≥992px): هياخد 3 من 12 (يعني 25% من العرض)، فكل 4 منتجات هييجوا جنب بعض في الصف الواحد.
  • row: A "row" that holds columns. It creates negative margin to counteract column padding.
  • col-12: The column takes the full width of the page (12 out of 12).
  • row g-4: A row with "gutters" (spacing between columns) of size 4 (1.5rem), both vertically and horizontally.
  • col-sm-6 col-lg-3: Full control over column size based on screen width:
    • Mobile (<576px): Default is 100% width (stacked), since no specific class is set.
    • Small (≥576px): Takes 6 of 12 (50% width), so 2 products per row.
    • Large (≥992px): Takes 3 of 12 (25% width), so 4 products per row.

  • modal: الكلاس الأساسي، وده بيخلي العنصر مخفي لحد ما يتم استدعاؤه.
  • fade: بيضيف أنيميشن "ظهور واختفاء ناعم" لما المودال يفتح أو يقفل.
  • id="modalProduct1": ده الـ ID المميز للمودال ده، وده اللي زرار "Quick View" بينده عليه.
  • modal-dialog-centered: بيخلي المودال يظهر في نص الشاشة بالظبط.
  • data-bs-toggle="modal": [JS] دي بتقول لبوتستراب: "يا عم البوتستراب، الزرار ده شغلته إنه يفتح مودال".
  • data-bs-target="#modalProduct1": [JS] دي بتقول: "وده الـ ID بتاع المودال اللي عايزك تفتحه".
  • modal: Base class, keeps element hidden until called.
  • fade: Adds smooth fade animation on open/close.
  • id="modalProduct1": Unique ID for this modal, targeted by the "Quick View" button.
  • modal-dialog-centered: Centers the modal vertically and horizontally.
  • data-bs-toggle="modal": [JS] Tells Bootstrap "This button's job is to open a modal".
  • data-bs-target="#modalProduct1": [JS] "And this is the ID of the modal to open".

<div id="carouselProduct1" class="carousel slide" data-bs-interval="false">
  • carousel slide: بيعرف العنصر إنه "سلايدشو" وفيه حركة انزلاق (Sliding animation).
  • data-bs-interval="false": [JS] دي مهمة جداً! بتوقف التقليب التلقائي (Auto-play). عشان مش عايزين الصور تجري ورا بعضها واليوزر بيتفرج، خليه هو اللي يقلب بنفسه.
  • object-fit-cover: كلاس مفيد جداً، بيخلي الصورة تملى المكان بتاعها من غير ما تتمط (Stretching)، وممكن يقص حتة صغيرة منها لو الأبعاد مش متطابقة.
  • carousel slide: Defines the element as a slideshow with sliding animation.
  • data-bs-interval="false": [JS] Very important! Disables Auto-play. We don't want images moving while the user is looking; let them control it.
  • object-fit-cover: Very useful class, ensures image fills its container without stretching, cropping slightly if dimensions don't match.

الجافاسكريبت (JS Bundle)

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
  • bootstrap.bundle.min.js: الملف ده جواه الجافاسكريبت بتاع Bootstrap وكمان مكتبة اسمها Popper.js.
  • بيعمل إيه هنا؟:
    1. المودالز (Modals): هو اللي بيسمع للـ clicks على الزراير اللي واخدة data-bs-toggle، وبيحسب مكان السكرول، وبيحط الخلفية الغامقة ورا المودال.
    2. الكاروسيل (Carousels): هو اللي بيحرك الصور، وبيغير كلاس الـ active، وبيخلي الـ touch شغال.
    3. من غير كود JS مخصص: عشان استخدمنا الـ Attributes والـ IDs صح (زي data-bs-target)، بوتستراب بيقوم بكل الشغل ده لوحده.
  • bootstrap.bundle.min.js: Contains Bootstrap's JS plus Popper.js library.
  • What does it do here?:
    1. Modals: Listens for clicks on buttons with data-bs-toggle, handles scrolling, and adds the dark backdrop.
    2. Carousels: Animates images, updates active class, and enables touch swiping.
    3. No Custom JS: Because we used Attributes and IDs correctly (like data-bs-target), Bootstrap does all this work automatically.
